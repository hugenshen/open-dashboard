# Spec v0.2.0 · 移动端布局与样式（C 档）

来源提案：[P001](../proposals/P001-mobile-layout-c.md)  
原型：[`frontend/hi-fi/dashboard-commercial.html`](../../frontend/hi-fi/dashboard-commercial.html)

## 范围

- 独立移动端布局：`dash.mobile.components`（6 列），与 PC `components` 坐标分离
- 组件池勾选上板；数据 / encode / 联动与 PC 共用
- 组件级 `styleSync`：同步 PC 样式，或写入 `mobile.components[].style` 覆盖
- 编辑器 PC / 移动画布切换 + 手机外框；预览「移动宽」渲染移动布局
- 列表「移动端」标识；`dash_sales` 预置精简移动布局

## 非范围

原生 App、数据大屏移动端、与 PC 不同的数据绑定。

## 关键 API（原型）

| 符号 | 作用 |
|------|------|
| `ensureMobile` / `COL_MOBILE` | 模型与栅格 |
| `hydrateMobileComp` / `resolveCompStyle` / `styleWriteBag` | 解析与样式读写 |
| `tabComps` / `commitLayout` / `gridCols` | 按 `editSurface` / 预览态分支 |
| `renderMobilePool` / `importAllToMobile` | 左侧组件池 |
| `seedSalesMobile` | 销售周报演示数据 |
