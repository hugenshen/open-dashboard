## 冻结决策

- 实时取数；文档不存 ResultTable
- 新建图仅 `source: inline`，不进仪表盘
- 引用图：`dashboardId + chartId`；默认 `view=published`
- 编辑器：Umo Editor（Vue3）；自定义 `reportChart` 节点
- 无看板 view 时引用图出数失败并占位（安全默认）
