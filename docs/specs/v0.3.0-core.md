## 1. 范围

冻结并工程化：

1. 仪表盘配置编辑（树、画布、图表 encode/style/senior、发布双副本）
2. 双层取数：`chartQuery` → `datasetQuery` → `ResultTable`
3. 移动端独立布局（`mobile_json` / 6 列 / styleSync）
4. Vue 3 + JDK 21 Spring Boot + PostgreSQL 脚手架

## 2. 技术栈

见 [../tech-stack.md](../tech-stack.md)。摘要：Vue3/Vite/Pinia/ECharts；JDK21/Spring Boot 3/Spring JDBC/Flyway；PostgreSQL 16；包名 `io.opendashboard`。

## 3. 配置模型

### 3.1 发布

- 编辑只写 `copy_type = draft`
- 观看 / 分享只读 `published`
- `publish`：draft 覆盖 published；`discardDraft` 丢弃未发布改动

### 3.2 实体

| 实体 | 表 | 说明 |
|------|-----|------|
| 树节点 | `de_dashboard` | folder / dashboard |
| 布局 | `de_dashboard_layout` | PC 网格 + **`mobile_json JSONB`** |
| 组件 | `de_dashboard_component` | PC 画布框 |
| 图表 | `de_chart_view` | encode / style / senior |
| 联动 | `de_dashboard_linkage` | 图间字段映射 |

### 3.3 `mobile_json` 形状

与高保 `props.mobile` / `dash.mobile` 对齐：

```json
{
  "enabled": true,
  "device": "iphone-14",
  "bg": "#f5f6f8",
  "components": [
    {
      "id": "m1",
      "refId": "<pc-component-id>",
      "x": 0, "y": 0, "w": 6, "h": 4, "z": 0,
      "styleSync": true,
      "style": {}
    }
  ]
}
```

- 列上限：`COL_MOBILE = 6`
- encode / dataset / linkages：**只认 PC 侧 chart**；移动项通过 `refId` 引用

### 3.4 PostgreSQL 要点

相对历史 MySQL 风格 [`schema.sql`](../schema.sql)：

- `LONGTEXT` → `TEXT` / `JSONB`
- `TINYINT` → `SMALLINT` 或 `BOOLEAN`
- 布局增加：`mobile_json JSONB NULL`
- Flyway：`backend/src/main/resources/db/migration/V1__dashboard.sql`

## 4. 取数协议

```text
FE ──POST /chartQuery/query──► ChartQuery
        │  load chart + board ACL
        │  encode + context → QuerySpec
        ▼
   POST /datasetQuery/execute（内部或同进程调用）
        │  dataset USE + CLS + RLS(FilterAST)
        │  LogicalPlan → dialect → DataSourcePort
        ▼
   ResultTable { columns, rows[][] }
        │
        ▼
   shapeForChart → ChartQueryResult（可含 series 等塑形）
```

规则：

- **style / senior 永不进 SQL**
- 前端可选 `inline.encode`（编辑预览未保存）
- `datasetQuery` 是唯一触达数据源的执行点
- 权限：看板 ACL 在 chartQuery；数据集 USE + FilterAST 在 datasetQuery（脚手架可 stub 放行）

契约：[`../openapi.yaml`](../openapi.yaml)。

## 5. 后端模块边界

```
io.opendashboard
├── api/                 # REST Controllers
├── application/         # ChartQuery / DatasetQuery / Canvas / Publish
├── domain/              # VO / 领域类型
└── infrastructure/
    └── persistence/     # JDBC repositories
```

脚手架最低端点：

| Method | Path | 行为（v0.3 scaffold） |
|--------|------|------------------------|
| GET | `/actuator/health` | UP |
| GET | `/api/dashboard/{id}` | stub detail |
| POST | `/api/chartQuery/query` | stub ResultTable 塑形 |
| POST | `/api/datasetQuery/execute` | stub columns/rows |
