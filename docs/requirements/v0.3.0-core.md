## 1. 目标

落地可运行的前后端工程骨架，使配置编辑、双层取数、移动端独立布局成为 **产品契约**，而非仅高保演示。

## 2. 用户故事与验收

### 2.1 列表与发布

| ID | 故事 | 验收 |
|----|------|------|
| R-LIST | 分析师浏览仪表盘文件夹树并打开看板 | `POST /dashboardTree/tree`；打开进入编辑器 draft |
| R-PUB | 分析师发布 / 丢弃草稿 | `publish` / `discardDraft`；观看只读 published |

### 2.2 PC 编辑器

| ID | 故事 | 验收 |
|----|------|------|
| R-CANVAS | 在网格画布增删、拖放、缩放组件 | 读写 draft components；乐观锁 contentId |
| R-ENCODE | 为图表绑定 dataset + encode（含多字段） | 配置落 `de_chart_view`；Style / Advanced 与 encode 分离 |
| R-QUERY | 每图独立刷新数据 | `POST /chartQuery/query`；筛选 / 联动进 context |
| R-DSQ | 数据集侧可执行标准查询 | `POST /datasetQuery/execute` → columns + rows[][] |

### 2.3 移动端（对齐 v0.2.0）

| ID | 故事 | 验收 |
|----|------|------|
| R-MOB-SURF | 编辑器切换 PC / 移动画布 | `editSurface: pc \| mobile`；移动态手机外框 |
| R-MOB-LAY | 独立 6 列布局 | `mobile.components` 与 PC 坐标分离；`mobile_json` 持久化 |
| R-MOB-POOL | 从 PC 组件池勾选上板 | 勾选创建布局项；数据 / encode 与 PC 共用 |
| R-MOB-STYLE | 样式同步或分设 | `styleSync`；分设写入 mobile 侧 style 覆盖 |
| R-MOB-VIEW | 预览「移动宽」与列表标识 | 预览用移动布局；`mobile.enabled` 列表标记 |

### 2.4 脚手架（工程）

| ID | 故事 | 验收 |
|----|------|------|
| R-FE | Vue3 应用可起 | `frontend`：`npm run dev`；路由 list / editor / preview |
| R-BE | Spring Boot 可起 | health + stub dashboard/chartQuery/datasetQuery |
| R-PG | PostgreSQL + Flyway | `docker compose up -d`；迁移含 `mobile_json` |
| R-REF | 高保仍可演示 | `npm run hi-fi` → prototypes |

## 3. Out of scope（本轮不做）

- 完整工作台、数据源连接器管理 UI、数据集建模完整 PRD
- 告警 / 跳转 / 导出 / 嵌入深化（commercial Phase 扩展）
- 把高保 HTML 业务逻辑一次性重写进 Vue
- 原生 App；与 PC 不同的数据绑定
- 行列权限引擎完整实现（契约与 stub 闸门即可）

## 4. 非功能

- 配置层禁止直查业务库；取数仅经 Dataset
- IDs 在 JSON 中为 string
- 文档 / OpenAPI 为契约源；实现落后于契约时以 stub 标明
