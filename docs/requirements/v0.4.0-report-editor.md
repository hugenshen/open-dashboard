> **交互基准（验收以之为准）**：[`prototypes/hi-fi/dashboard-commercial.html`](../../prototypes/hi-fi/dashboard-commercial.html) 顶栏「报告」模块。  
> **产品目标实现**：Vue 3 + [Umo Editor](https://github.com/umodoc/editor)（Tiptap3）+ Spring Boot；契约见 [`../openapi.yaml`](../openapi.yaml)、规格见 [`../specs/v0.4.0-report-umo-charts.md`](../specs/v0.4.0-report-umo-charts.md)。  
> **来源提案**：[P003](../proposals/P003-report-umo-charts.md)

高保为交互与信息架构的 **唯一基准**；实现可用 Umo 原生能力替代高保里 `contenteditable` 模拟，但 **Ribbon 分区、工具槽业务入口、两向导步骤、节点数据模型、实时取数** 不得弱于高保。

---

## 1. 目标

分析师可在 **在线报告** 中撰写排版正文，并通过「工具」插入：

1. **引用仪表盘图表**（非整盘导入，多选按序插入）  
2. **仅属于报告的新建图表**（不写回仪表盘）

阅读 / 编辑预览均 **实时取数**；文档只存配置与正文，不存查询结果行。

---

## 2. 信息架构与路由

### 2.1 模块入口

| 项 | 约定 |
|----|------|
| 顶栏模块 | 「报告」（与工作台 / 数据源 / 数据集 / 仪表盘并列） |
| 高保路由 | `#/report/list/...`、`#/report/editor/:id` |
| 产品路由（建议） | `/reports`、`/reports/:id/edit`（与脚手架对齐即可，语义等同 list / editor） |

### 2.2 列表页

- 左：文件夹树 + 报告列表（搜索、状态：草稿 / 已发布 / 有改动）
- 右：当前报告摘要（图表块数、引用看板数、报告内新建数、打开编辑器）
- 操作：新建报告、打开编辑器；双击列表项进入编辑器

### 2.3 编辑器页壳（对齐 Umo Ribbon）

自上而下：

1. **宿主栏**：← 列表 · 可改报告标题 · 状态标签 · 收起/显示图表配置 · 发布  
2. **Ribbon 菜单**：开始 / 插入 / 表格 / 工具 / 页面 / 视图 / 导出；**默认「开始」**  
3. **Ribbon 内容区** + 右上角 **保存状态点**（未保存 / `HH:mm保存`）  
4. **主区三栏**：页面大纲（可隐）| A4 页正文 | 右侧图表 inspector（可收起）  
5. **状态栏**：页面大纲开关 · 页面/Web 视图 · 字数 · 缩放 ±

### 2.4 正文区

| 项 | 验收 |
|----|------|
| 页面 | 默认 A4；四角裁切线；可切 Web 视图 |
| 编辑 | 正文 `contenteditable` / Umo 文档区可直接改标题与段落 |
| 开始区 | 样式卡：正文、标题 1–3；格式命令（粗斜下划、对齐、列表等，与 Umo 开始菜单一致即可） |
| 页面大纲 | 标题文案固定为 **「页面大纲」**；**默认隐藏**；可从状态栏 / 视图 / 插入侧开关打开；含标题与图表块锚点 |

Umo 内置「插入 / 表格 / 页面 / 视图 / 导出」能力可按 Umo 默认启用；**本期硬验收**的是壳布局 +「工具」业务入口 + 图表节点行为（其余 Umo 按钮可灰态或走原生）。

## 3. 用户故事

### 3.1 列表与文档生命周期

| ID | 故事 | 验收 |
|----|------|------|
| RR-LIST | 分析师浏览报告列表并打开编辑器 | 路由进入 list；选中报告后进入 editor；URL 含报告 id |
| RR-CREATE | 新建空白报告 | `POST /report`；进入编辑器；含默认标题块 |
| RR-SAVE | 保存文档 | 脏状态显示「文档未保存」；保存 → `PUT /report/{id}/doc`（content + contentId）；成功后保存点更新 |
| RR-PUB | 发布报告 | 宿主栏「发布」→ `POST /report/{id}/publish`；状态变为已发布 |
| RR-REOPEN | 再打开不丢配置 | 刷新 / 重进后正文与 `reportChart` attrs 与保存时一致 |

### 3.2 编辑器壳

| ID | 故事 | 验收 |
|----|------|------|
| RR-RIBBON | Ribbon 七区可见且默认可「开始」 | 菜单文案与顺序：开始/插入/表格/工具/页面/视图/导出 |
| RR-START | 开始区可改段落样式与格式 | 正文/标题1–3 样式卡；选中文本可粗斜等 |
| RR-STATUS | 状态栏与保存点 | 页面大纲开关、页面/Web、字数、缩放；右上角保存状态点 |
| RR-PAGE | A4 + 裁切线 + 大纲默认隐 | 页面视图下四角裁切线；大纲默认不显示；标题为「页面大纲」 |

### 3.3 引用仪表盘（工具槽）

| ID | 故事 | 验收 |
|----|------|------|
| RR-REF | 从工具打开「引用仪表盘」 | 入口在 **工具** Ribbon 槽（Umo `#toolbar_tools`），非整盘一键导入 |
| RR-REF-WIZ | 三栏向导完成多选插入 | 见 §4.1；确认后按勾选顺序插入多个 `reportChart`（`source=dashboard`） |
| RR-REF-STORE | 文档只存引用键 | 节点 attrs 含 `dashboardId` + `chartId`（+ 默认 `view=published`）；**不含** ResultTable |
| RR-REF-LIVE | 引用图实时取数 | NodeView → `POST /chartQuery/query`（dashboardId+chartId）；看板数据变后刷新可见 |

### 3.4 新建图表（仅报告）

| ID | 故事 | 验收 |
|----|------|------|
| RR-NEW | 从工具打开「新建图表」 | 入口在 **工具** 槽；文案体现「仅报告」 |
| RR-NEW-WIZ | 左右分栏向导，确认才插入 | 见 §4.2；取消不插入；确认后 `source=inline` |
| RR-NEW-SCOPE | 不写回仪表盘 | 插入后仪表盘组件/chartView **无**对应新增项 |
| RR-NEW-INSP | 插入后可继续配置 | 自动选中节点、展开右侧 inspector（数据/样式/高级）；字段银行 + 编码槽可用 |
| RR-NEW-LIVE | inline 实时取数 | `POST /chartQuery/query` 纯 inline（无 dashboardId）；不落库结果行 |

### 3.5 报告图表块通用

| ID | 故事 | 验收 |
|----|------|------|
| RR-SRC | 双来源 | `source` 仅为 `dashboard` \| `inline` |
| RR-INSP | 右侧面板对齐看板思路 | 数据：字段银行 + 编码槽；样式：标题/高度等展示壳；高级：刷新/删除；引用源 encode 以看板为准 |
| RR-DEL | 删除节点 | 删除 inline 即删配置；删除引用不影响原看板 |
| RR-PERM | 无权限明确错误 | 无数据集 USE / 无看板 view 时占位错误，不白屏 |

## 4. 交互规格（逐步）

### 4.1 引用仪表盘 · 三栏向导

触发：Ribbon「工具」→ **引用仪表盘**。

```text
打开弹层「引用仪表盘 · 选择图表」
  ├─ 左栏「仪表盘」：有权 view 的看板列表（显示可引用图表数）
  │     切换看板 → 清空已选、重置搜索与中栏列表
  ├─ 中栏「图表」：当前看板图表多选
  │     · 搜索：名称 / 类型
  │     · 全选 / 清空
  │     · 单击行：聚焦预览；勾选框切换选中；双击切换选中
  ├─ 右栏「效果预览」：当前聚焦图实时预览（标注实时取数）
  │     · 底部「已选 N 张 · 将按勾选顺序插入」
  └─ 底栏：取消 | 「插入所选图表」（未选 → 提示，不关闭）
确认 → 按勾选顺序在文档中插入节点；选中最后一张；展开 inspector
```

硬性约束：

- **非整盘导入**（无「导入整个仪表盘」）
- 文档只存 `dashboardId` + `chartId`（可附显示用 `title` / `height`）
- 编码以仪表盘原图为准；报告内默认可改展示壳（标题、高度）；inspector 可换看板/图表

### 4.2 新建图表（仅报告）· 左右分栏向导

触发：Ribbon「工具」→ **新建图表**。

```text
打开弹层「新建图表（仅报告）」
  ├─ 左：效果预览（改配置即刷新；实时聚合 / chartQuery）
  └─ 右：配置
        1. 基础：标题（可空→自动生成）、图表类型
        2. 数据集（须 USE）
        3. 字段银行（点击填入当前槽位）
        4. 编码槽：维度 / 指标 /（透视）列维度 · 聚合 · 数值格式 · 高度(px)
底栏：取消 | 「确认插入」
  · 缺数据集或（非 table）缺指标 → 提示，不插入
确认 → 插入 source=inline 节点 → 选中 → 右侧 inspector 默认「数据」Tab
```

硬性约束：

- 配置 **只存在于报告文档节点**；**不**写入 `de_chart_view` / 仪表盘组件  
- 一期不提供「同步到仪表盘」  
- 插入前向导内预览不得落库；插入后仍走实时 `chartQuery`

### 4.3 右侧 inspector（插入后）

| Tab | dashboard 源 | inline 源 |
|-----|--------------|-----------|
| 数据 | 换看板/图表；展示标题；encode 只读（跟看板） | 数据集 + 字段银行 + 编码槽 + 聚合/格式（对齐仪表盘编辑器） |
| 样式 | 标题、高度等展示壳 | 同左 |
| 高级 | 来源摘要、刷新取数、删除块 | 同左 |

未选中图表时：提示「点选报告中的图表进行配置」。

### 4.4 取数与持久化

```text
保存文档：Umo/Tiptap JSON（含 reportChart attrs）→ PUT /report/{id}/doc
出数：NodeView / 向导预览 → POST /chartQuery/query
  · dashboard：{ dashboardId, chartId, view, client: report, context }
  · inline：{ inline: { datasetId, chartType, encode, … }, client: report, context }
禁止：把 ResultTable / rows 写入 content_json
```

## 5. 非功能

| 项 | 要求 |
|----|------|
| 实时性 | 编辑预览与阅读默认实时取数；导出是否快照属后续议题 |
| 安全 | 引用图：读者无看板 view → 拒绝出数 + 占位（一期）；inline：仅数据集 USE + RLS/CLS |
| 契约 | IDs 均为 string；OpenAPI 为 API 源 |
| 性能 | 单报告多图各自请求；切换选中不应导致整页重载丢失光标（产品实现） |
| 兼容 | 依赖 v0.3 脚手架与 `chartQuery` / `datasetQuery` |

---

## 6. Out of scope（本期不做）

- 报告级全局筛选联动多图（可留 `context`）
- 新建图「保存到仪表盘」
- 文档内持久化查询结果 / 离线包
- Umo 协同服务器、批注深度、Mobile Editor
- Word/PDF 导出时的图表光栅快照策略（可后议；默认产品行为仍是实时）

### 7.2 编辑器壳（对齐高保 / Umo）

- [ ] Ribbon：开始/插入/表格/工具/页面/视图/导出；默认「开始」
- [ ] 开始区：正文/标题1–3 样式卡 + 常用格式命令
- [ ] 正文可直接编辑标题与段落
- [ ] A4 页 + 四角裁切线；可切换页面 / Web 视图
- [ ] 页面大纲标题为「页面大纲」，**默认隐藏**，状态栏可开关
- [ ] 状态栏含字数与缩放；右上角保存状态点（脏/已保存）

### 7.3 工具 · 引用仪表盘

- [ ] 入口位于 **工具** 槽（`#toolbar_tools`）
- [ ] 三栏：左看板 → 中多选+搜索 → 右实时预览

### 7.4 工具 · 新建图表（仅报告）

- [ ] 入口位于 **工具** 槽

- [ ] 删除 inline 不影响看板；删除引用不影响看板原图
