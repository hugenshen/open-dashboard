# 产品路线图

产品是什么见 [../README.md](../README.md)。本目录回答 **下一步为什么做、给谁做、做什么、不做什么**。怎么实现、怎么验收仍在 [proposals/](../../proposals/)。

对标常见的 Now / Next / Later / Won’t（Atlassian、多数 SaaS）：按**置信与承诺**分夹，不按日历。每夹 **一份 README**，每条写清含义，不再拆 `Pxxx.md`、也不按月建文件。

| 状态 | 含义 | 打开 |
|------|------|------|
| 进行中 | Now：正在做或已承诺推进 | [in-progress/](./in-progress/) |
| 已完成 | Shipped：用户已能用，只追溯 | [done/](./done/) |
| 计划中 | Next / Later：方向清楚，尚未承诺开工 | [planned/](./planned/) |
| 搁置 | 讨论过，当前不排 | [parked/](./parked/) |
| 不做 | Won’t：明确排除 | [wont/](./wont/) |

每条固定写这些（没有就写「—」）：

| 列 | 回答 |
|----|------|
| 给谁 | 哪类用户会变好 |
| 要解决什么 | 用户侧变化（outcome），不是组件名 |
| 范围 | 做哪些 · **不做**哪些 |
| 里程碑 | v0.x，表示能力批次，不是发版日 |

改状态：改提案文首 `status`，把该条从旧夹 README 挪到新夹。提案目录不搬家。
