AI Harness 集成

会话元数据与消息写入 Java de_conversation*（GET/POST /api/conversations）。Agent 走 /harness/v1/conversations/{id}/runs（SSE）；若 Harness 本地没有该 id，按 Java 会话 id 补建运行时文件。Harness 侧已拆出 RunController、EventStreamRecorder、TraceStore、ContextBuilder 与 ToolGateway 骨架，SSE 事件可写入运行 trace 并通过 /harness/v1/conversations/{id}/runs/{runId}/trace 读回；本地会话、知识和用户记忆已按 X-Workspace-Id scope 过滤，默认 default 兼容旧运行。Java 不跑 LLM。

工作区治理入口

前端 AppShell 从 /api/auth/me 获取当前工作区和可切换工作区；所有请求通过 src/api/http.ts 附加 X-Workspace-Id。用户端 /data-plaza 展示可见资产、我的数据和申请；管理端 /workspace-admin 展示成员、用户组、角色权限和数据策略入口。

意图分流

Harness resolve_intent：显式 ask | insight | gen，或从文案推断。

  • ask / insight：走上方问数轨，不进 Lead 生成环
  • 换一个问数问题：不生成 SQL，按当前表字段反问可点问题；点选后再 ask
  • gen：规划图表 → layout → od_emit_patch
  • 「为什么 / 下滑」倾向 insight；结果卡可出解读，不复用上一张问数图当诊断

质检 / 规划 分析师自己排版。 LLM critic（FinalAnswerCheck）+ SOPPlan 诊断。 TodoList / 澄清中间件；无 BI 质检。 确定性质检闸：假环比、同维饼图、过密折线、明细表。LLM 跳过也会被 layout 兜住。

DataEase：抄什么 / 不抄

优势（对方）：画布、数据集、发布分享成熟；SQLBot 术语/示例/多表选表完整；分析师可控。

劣势（对方）：没有「一句话出整页看板」；问数不写 DV；AI 与 BI 两套产品。

  • OD 抄：DS→Dataset→Chart→Canvas 分层；编辑器浮层壳；问数默认不写画布
  • OD 不抄：getData 整 DTO、模板市场当生成、iframe 整站 SQLBot

JoyAgent：抄什么 / 不抄

优势（对方）：NL2SQL + 诊断归因强；TableRAG / DGP 治理；报告叙事完整；BirdSQL 成绩。

劣势（对方）：HTML/PPT ≠ 可运营看板；结果行容易进文档；没有 draft/publish 生命周期。

  • OD 抄：先问数再落配置；「分析后再可视化」收成确定性质检闸
  • OD 不抄：结果行进 HTML、SOP 诊断、TableRAG、DGP 预编织（洞察归 P005）

DeerFlow：抄什么 / 不抄

优势（对方）：Lead + 中间件 + SSE 成熟；Plan/澄清/Todos；Skills 可扩展；适合开放任务。

劣势（对方）：无 BI schema/query/dashboard 真相；沙箱文件不能当看板运行；部署重（Docker/E2B）。

  • OD 抄：write_todos planner、SSE run、工具 name+schema+execute、Session
  • OD 不抄：bash/沙箱当产物、LangGraph 整套中间件、通用研究 Agent

OD 相对三家的优势

  • 产物可运营：生成的是可编辑、可发布、可分享的 Dashboard draft，不是静态页或 PPT。
  • 配置与数据分离：布局只存 encode；刷新走 chartQuery。问数 SQL 不进入画布真相。
  • Java 零 LLM：权限、取数、Patch 在 Java；模型失败可降级确定性规划，看板仍能出。
  • 空稿拦截 + 质检闸：无有效行不 emit；假环比/同维饼图/过密折线有规则修，不依赖第二次 LLM 心情。
  • 双意图不混：问数默认 ephemeral；生成才写整页。分析师仍可用 DataEase 式画布手改。

OD 相对三家的劣势

  • 没有 JoyAgent 级诊断 / TableRAG / 数据治理协议
  • 没有 SQLBot 术语库、SQL 示例、多表 embedding 选表
  • 没有 DeerFlow 沙箱分析与通用 Skills 生态
  • 图表类型与画布能力窄于 DataEase DV
  • 跨表规划尚未闭环
  • Harness 未进 Docker Compose，不是开箱即用 AI
