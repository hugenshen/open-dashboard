DataEase：抄什么 / 不抄

优势（对方）：画布、数据集、发布分享成熟；SQLBot 术语/示例/多表选表完整；分析师可控。

劣势（对方）：没有「一句话出整页看板」；问数不写 DV；AI 与 BI 两套产品。

  • OD 抄：DS→Dataset→Chart→Canvas 分层；编辑器浮层壳；问数默认不写画布
  • OD 不抄：getData 整 DTO、模板市场当生成、iframe 整站 SQLBot

JoyAgent：抄什么 / 不抄

优势（对方）：NL2SQL + 诊断归因强；TableRAG / DGP 治理；报告叙事完整；BirdSQL 成绩。

劣势（对方）：HTML/PPT ≠ 可运营看板；结果行容易进文档；没有 draft/publish 生命周期。

  • OD 抄：先问数再落配置；「分析后再可视化」收成确定性质检闸；对话分析报告（P016）抄 JoyAgent 右侧 HTML/MD 文件预览，但是聚合快照（≤200 行 / 15s），不是可刷新看板
  • OD 不抄：把结果行写进 Dashboard 布局、SOP 诊断、TableRAG、DGP 预编织；看板解读进 Umo（禁止内嵌结果行）仍归未接受的 P005

DeerFlow：抄什么 / 不抄

优势（对方）：Lead + 中间件 + SSE 成熟；Plan/澄清/Todos；Skills 可扩展；适合开放任务。

劣势（对方）：无 BI schema/query/dashboard 真相；沙箱文件不能当看板运行；部署重（Docker/E2B）。

  • OD 抄：write_todos planner、SSE run、工具 name+schema+execute、Session
  • OD 不抄：bash/沙箱当产物、LangGraph 整套中间件、通用研究 Agent

OD 相对三家的优势

  • 产物可运营：生成的是可编辑、可发布、可分享的 Dashboard draft，不是静态页或 PPT。
  • 配置与数据分离：布局只存 encode；刷新走 chartQuery。问数 SQL 不进入画布真相。
  • Java 零 LLM：权限、取数、Patch 在 Java；模型失败可降级确定性规划，看板仍能出。
  • 空稿拦截 + 质检闸：无有效行不 emit；假环比/同维饼图/过密折线有规则修，不依赖第二次 LLM 心情。
  • 双意图不混：问数默认 ephemeral；生成才写整页。分析师仍可用 DataEase 式画布手改。

OD 相对三家的劣势

  • 没有 JoyAgent 级诊断 / TableRAG / 数据治理协议
  • 没有 SQLBot 术语库、SQL 示例、多表 embedding 选表
  • 没有 DeerFlow 沙箱分析与通用 Skills 生态
  • 图表类型与画布能力窄于 DataEase DV
  • 跨表规划尚未闭环
  • Harness 未进 Docker Compose，不是开箱即用 AI

鉴权
