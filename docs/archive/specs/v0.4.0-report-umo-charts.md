## 1. 冻结决策

| # | 决策 |
|---|------|
| D1 | **实时取数**；`content_json` **不**存 ResultTable / rows |
| D2 | 新建图仅 `source: inline`，**不**写入仪表盘 / `de_chart_view` |
| D3 | 引用图：节点存 `dashboardId + chartId`；默认 `view=published` |
| D4 | 编辑器：Umo Editor（Vue3 + Tiptap3）；自定义原子节点 `reportChart` + Vue NodeView |
| D5 | 业务入口在 Ribbon **工具** 槽：`#toolbar_tools`（**不是** `#toolbar_insert`） |
| D6 | 无看板 view 时引用图出数失败并占位（安全默认） |

### 3.2 Umo 集成点

对照 [Umo 插槽文档](https://dev.umodoc.com/cn/docs/editor/slots)：

| 集成点 | 约定 |
|--------|------|
| 扩展 | `extensions: [ReportChart, …]` |
| Ribbon | 使用 Umo 默认菜单：开始/插入/表格/工具/页面/视图/导出；默认打开「开始」 |
| **业务槽** | `#toolbar_tools`：按钮「引用仪表盘」「新建图表」（对应高保工具区 `is-slot`） |
| 文档 | `editor.getJSON()` / `setContent` ↔ `PUT/GET /report/{id}/doc` |
| 页面 | 默认 page（A4）布局；支持 Web 布局切换；保留页角裁切视觉（Umo 页面模式） |
| 大纲 | Umo 页面大纲；产品文案/验收称「页面大纲」；默认隐藏 |
| 状态栏 | 大纲开关、页面/Web、字数、缩放；宿主侧保存状态点（可叠在 toolbar actions） |
| 右侧栏 | 选中 `reportChart` 时展示数据/样式/高级（可用 Umo aside 槽或自建旁栏，行为对齐高保） |

> P003 初稿曾写 `#toolbar_insert`；以高保与本规格为准，统一为 **`#toolbar_tools`**。

### 3.3 `reportChart` 节点

Tiptap：`atom`、`selectable`、`draggable`；HTML：`div[data-type="report-chart"]`。

```ts
type ReportChartAttrs = {
  id: string                       // 报告内稳定 id
  source: 'dashboard' | 'inline'
  // source=dashboard
  dashboardId?: string | null
  chartId?: string | null
  view?: 'published' | 'draft'     // 默认 published
  // source=inline
  datasetId?: string | null
  chartType?: string               // bar | hbar | line | area | pie | kpi | table | pivot | …
  encode?: Record<string, unknown>
  style?: Record<string, unknown>
  senior?: Record<string, unknown>
  // 展示壳（共用）
  title?: string
  width?: 'full' | 'half' | number
  height?: number                  // px，高保默认引用 280 / 新建 320
}
```

NodeView：

- 挂载 / 刷新 → 调 `chartQuery`（`client: report`）→ 渲染  
- 选中 → 驱动右侧 inspector  
- **禁止**把查询结果写回 attrs

### 3.4 两向导（与高保逐步一致）

**引用仪表盘**（`InsertDashboardChartDialog`）：

1. 左：看板列表（需 view）  
2. 中：图表多选 + 搜索 + 全选/清空  
3. 右：聚焦图实时预览  
4. 确认 → 按勾选顺序 `insertContent` 多个节点；非整盘导入  

数据来源：既有看板树 / 画布 API 列组件与 chartId。

**新建图表**（`CreateInlineChartWizard`）：

1. 左：实时预览  
2. 右：数据集 → 类型 → 字段银行 → 维/指/聚合/格式/高度/标题  
3. 确认 → 插入单一 inline 节点 → 打开 inspector  

字段银行 / 编码槽交互对齐仪表盘编辑器（可先简化版，槽位语义一致）。

## 4. 数据模型（配置库）

| 表 / 字段 | 说明 |
|-----------|------|
| `de_report` | id, name, status (`draft` \| `published` \| `publishedWithDraft`), version, … |
| `de_report_doc` | report_id, copy_type (`draft` \| `published`), `content_json` JSONB（Umo/Tiptap doc）, content_id |

权限资源：`REPORT`（manage / edit / view）；取数时再过看板 view / 数据集 USE。

脚手架阶段可用内存 store；表结构进 Flyway 时保持上述语义。

## 5. API（契约摘要）

完整定义见 [`openapi.yaml`](../openapi.yaml)。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/report` | 列表 `ReportMetaVO[]` |
| POST | `/report` | 创建（name）→ `ReportDetailVO` |
| GET | `/report/{id}` | 元数据 + **draft** `content` |
| PATCH | `/report/{id}` | 改元数据（如 name） |
| DELETE | `/report/{id}` | 删除报告 |
| PUT | `/report/{id}/doc` | 保存文档 JSON；体：`content` + `contentId`；冲突 409 |
| POST | `/report/{id}/publish` | 发布 draft → published |
| POST | `/report/{id}/discardDraft` | 丢弃草稿（有 published 时） |
| POST | `/chartQuery/query` | 看板路径或 **纯 inline**（无 `dashboardId`） |

### 5.1 chartQuery（报告）

```text
source=dashboard:
  POST /chartQuery/query {
    dashboardId, chartId, view, client: "report", context
  }

source=inline:
  POST /chartQuery/query {
    dashboardId: null,
    inline: { datasetId, chartType, encode, style?, senior? },
    client: "report",
    context
  }
```

- style **永不**进 SQL  
- 报告 NodeView **不**直连 `datasetQuery`  
- 纯 inline：只校验数据集 USE（+ RLS/CLS），不做看板 ACL

## 7. 权限矩阵（摘要）

| 动作 | 报告 | 看板 | 数据集 |
|------|------|------|--------|

| 阅读含图报告 | view | 引用图需看板 view（一期） | USE + RLS |
| 编辑 inline | edit | — | USE |
