我的数据 去问数

只有已获权并添加的资产会进入“我的数据”。对话分析和 SQLBot 继续从 Java 权限中心获取 askable 集合。

权限说明

广场可见不等于可消费。未获权资产只展示名称、业务说明、负责人、敏感等级和申请条件，不展示字段明细、样例数据或查询结果。

已获权
可以添加到我的数据，并进入问数或看板消费。
可申请
只能看业务说明，提交用途、有效期和期望动作。
申请中
审批通过后由 Java 权限中心写入 dataset:use、行列策略和工具权限。

管理边界

管理端“数据集”负责发布、字段语义、行列策略和审批；用户端“数据广场”只负责发现、添加和申请消费。
