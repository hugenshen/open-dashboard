端到端链路

1. 登录Java 建立 userId 和登录态
2. 选工作区服务端确认 workspaceId 和角色
3. 管理端治理发布可问、可申请数据和权限策略
4. 用户端使用数据广场发现，再由对话分析调用 Harness run
5. 审计回放记录工具、知识、记忆和权限决策
