有效权限计算

Java 统一计算工作区成员、项目组角色、资源 ACL、数据策略和工具策略。Harness 只消费授权快照，并在工具调用时再次让 Java 校验。

1. 身份
userId 来自登录或外部网关
2. 工作区
workspaceId 来自服务端当前上下文
3. 资源
数据集、看板、报告和知识按 ACL 过滤
4. 工具
Tool Gateway 根据 Java 下发清单开放
