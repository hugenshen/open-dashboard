## 背景

对标 SQLBot / DataEase 之后做了工作区、数据市场申请、成员授权。真实翻车：注册新用户默认能看到别人创建的仪表盘；权限做完后数据集下拉没值、选成员没人；「以前的数据源怎么不见了」——有时是没落库，有时是过滤器过严却没有空状态说明。

用户侧和管理侧不是同一套心智：用户端是「我的 / 企业资产」，管理员才有多工作区；不要把工作区切换器塞进所有人的顶栏。

## 解决方案

- **fail-closed**：没授权就没有数据集、没有问数、没有别人的草稿/已发布板
- 数据市场申请 → 审批 → 申请人才能看见/问数；审批流要能在界面找到，不能只存在 API
- 从广场点「问数」必须带上该数据集上下文（见对话三轨学习）
- 配置「给 A 整表、给 B 行列」是 P008/P009 的产品能力，实现前先读提案开发入口，不要按聊天即兴加表
- 列表删除只留一个入口；批量删除和行内删除叠在一起会让用户害怕

## 经验总结

- 权限相关改动**必须**用新注册用户走一遍：注册 → 加入工作区 → 申请数据 → 审批 → 问数/看板。只拿管理员账号点通不算验过。
- 数据「消失」先查：连的是哪套库、workspaceId 是否变了、接口是不是还在返回 mock。
- 不要把治理菜单（知识、成员、数据源）做成难用的后台表单堆砌；列表优先、筛选在上、操作列完整可见。
- 分享链接是只读：不要出现编辑加号、SQLBot、新手指引。
